Design for the way people actually think

A free, open toolkit for designing, auditing and writing digital products for neurodivergent and cognitively diverse people.

Most accessibility reviews check contrast, alt text and keyboard focus, then stop. That leaves out the largest group of disabled users. This kit covers what comes after those checks: attention, memory, reading, numbers, stress and trust.

The twelve rules, if you only read one thing

These serve every profile at once. If a project can only do a few things, do these.

  1. One primary action per screen.
  2. Plain language, around 9th-grade reading level or below.
  3. Left-aligned body text. Never justify. Line length 45 to 75 characters.
  4. Line height at least 1.5. Paragraph spacing at least twice the font size.
  5. Never rely on colour alone. Use colour, shape and text together.
  6. No unrequested motion. Honour prefers-reduced-motion.
  7. Never require recall. Carry values forward and let people paste anything.
  8. No time limits. If one is unavoidable, warn, allow more time and never wipe data.
  9. Errors name the field, say what is wrong and say how to fix it.
  10. Say what happens next, before the action and after it.
  11. Consistency beats cleverness.
  12. Give control instead of choosing for people.

Three things this kit insists on

A difference, not a deficit

Estimates put 15 to 40 percent of people as having neurodivergent traits. Traits are spread across everyone. Anyone under stress has trouble with working memory.

No hidden "modes"

A dyslexia mode buried in settings is a way of not fixing the product. Make the accessible version the default, then add user control on top.

Test with real people

Guidelines reduce obvious harm. They do not replace testing with neurodivergent people.

Use it with Claude

The neurodiversity-design folder is an installable skill for Claude. Once installed, Claude uses it when you ask for an accessibility review, UI copy or design work for any of the 16 profiles.

git clone https://github.com/bairamilona/cognitive-accessibility-kit.git
cd cognitive-accessibility-kit
./build.sh   # produces dist/neurodiversity-design.skill

In the Claude desktop app, open Settings, then Capabilities, and add the .skill file. In Claude Code, copy the neurodiversity-design folder into ~/.claude/skills/.

Try asking

  • "Review this signup flow for cognitive accessibility."
  • "Rewrite these error messages so they are actually usable."
  • "Our checkout has a 10-minute timer. What is the case for removing it?"
  • "Make this dashboard work for someone with dyscalculia."
